# 事件推送

插件通过 JX3API 的 WebSocket 事件通道接收游戏事件，并按后台配置推送到 AstrBot 会话。事件目录、字段排版移植自参考插件 `astrbot_plugin_jx3_miemie`。

## 配置

| 配置键 | 默认值 | 说明 |
| --- | --- | --- |
| `event_push_enabled` | `false` | 是否连接事件通道 |
| `event_push_wss_url` | `wss://socket.nicemoe.cn` | 事件 WebSocket 地址，后台可改 |
| `event_push_token` | 空 | 事件令牌；**留空自动复用 JX3API Token** |
| `event_push_actions` | `[2001..2006]` | 要推送的事件编号 |
| `event_push_sessions` | `[]` | 接收推送的 AstrBot 会话 ID |

- 连接 URL 会附加 `toekn=<token>` 查询参数（JX3API 官方 SDK 的历史拼写）。
- 令牌留空时使用 `jx3api_token`；JX3API Token 更新后事件通道也会自动重连。
- 事件通道依赖 AstrBot 自带的 `aiohttp`；缺少时后台会显示“未安装 aiohttp”，不影响查询功能。

## 消息格式

JX3API 下发：

```json
{
  "action": 1001,
  "status": "success",
  "message_id": "可选，用于去重",
  "detail": {
    "zone": "电信区",
    "server": "梦江南",
    "name": "张三",
    "event": "三尺青锋",
    "level": "25",
    "time": 1792843477
  }
}
```

插件输出示例：

```text
【奇遇触发】
大区：电信区
服务器：梦江南
角色：张三
奇遇：三尺青锋
等级：25
时间：2026-10-24 20:04:37
```

- `detail` 缺失时回退到 `data` 字段；都不是对象则忽略。
- `status != success` 的事件忽略。
- 显式带 `event_id` / `eventId` / `message_id` 的事件会去重（300 秒窗口）；没有 ID 的相同内容不会被误删。
- 未知 action 忽略。

## 推送目标

- 全局 `event_push_sessions` 列表仍可在后台维护，每行一个 AstrBot 会话 ID。
- 每个会话可以单独开启 / 关闭事件；没有单独订阅的会话沿用后台的全局事件选择。
- 「推送 <事件名> 开启 / 关闭」按中文事件名修改当前群订阅，例如「推送 开服状态 开启」。
- 「推送 开启 / 关闭」切换当前群的总开关（关闭后该群不再接收任何事件）。
- 「推送列表」查看当前群全部事件的 ✅ / ⬜ 状态。
- 后台「事件推送 → 会话订阅状态」可选择会话查看并保存同一份开关。
- 免费事件发给所有订阅会话；付费闸门开启时，令牌事件只发给授权有效的会话。

## 连接与重连

- 连接成功后每 30 秒发送 `{"action": -1}` 心跳。
- 断开后按 2、4、8……最多 30 秒退避重连。
- 后台「保存并重连」或「重连」按钮会立即重建连接。
- 状态字段：`enabled`、`running`、`connected`、`last_error`、`received`、`last_event`。
- 错误信息中的令牌会被替换成 `***`。

## 命令

```text
推送 开服状态 开启       # 当前群订阅「开服状态」
推送 奇遇触发 关闭       # 当前群取消「奇遇触发」
推送 开启                # 当前群开启全部事件
推送 关闭                # 当前群关闭全部事件
推送列表                 # 查看全部事件状态
推送 状态                # 当前群已开启事件
```

## 排障

| 现象 | 处理 |
| --- | --- |
| 状态“未安装 aiohttp” | AstrBot 环境缺少 aiohttp；正常 AstrBot 自带，检查依赖 |
| 一直“等待连接” | 检查 `wss://socket.nicemoe.cn` 是否可访问、JX3API Token 是否有效 |
| 连接后没有消息 | 确认事件已在后台勾选、目标会话已添加；免费事件仍需选择 |
| 令牌事件没有推送 | 付费闸门开启时检查该群授权是否有效；或先关闭付费闸门 |
| 重复消息 | 事件没有 `message_id` 时无法去重，属于上游行为 |
